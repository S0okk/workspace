# Daily Bot - Telegram бот для дневных вопросов и стриков

Telegram бот, который помогает пользователям отвечать на ежедневные вопросы (дейлики), отслеживать прогресс и сохранять день-стрик как в Duolingo 🔥

## ✨ Особенности

- **Дейлики** - Ежедневные вопросы, адаптированные под интересы пользователя
- **Day-Streak система** - Отслеживание дневных стриков как в Duolingo
- **Персонализация** - Выбор интересов для персонализированного контента
- **Напоминания** - Автоматические напоминания о дейликах
- **Статистика** - Отслеживание прогресса и достижений
- **Оптимизация** - Безопасный и быстрый код
- **Асинхронность** - Полностью асинхронная архитектура

## 🚀 Установка

### Требования
- Python 3.8+
- Telegram Bot Token

### Шаги установки

1. **Клонируйте репозиторий и перейдите в папку:**
```bash
cd workspace/bot
```

2. **Создайте единое виртуальное окружение в корне workspace и активируйте его:**
```bash
# находясь в папке workspace/bot
python -m venv ../.venv
source ../.venv/bin/activate  # На Windows: ..\.venv\Scripts\activate
```

3. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

4. **Создайте файл `.env`:**
```bash
cat > .env << EOF
TELEGRAM_BOT_TOKEN=your_token_here
EOF
```

Замените `your_token_here` на ваш Telegram Bot Token от BotFather.

5. **Запустите бота:**
```bash
python main.py
```

## 📋 Команды бота

| Команда | Описание |
|---------|---------|
| `/start` | Начать работу с ботом |
| `/help` | Справка по командам |
| `/daily` | Ответить на дневное задание |
| `/streak` | Посмотреть свой стрик 🔥 |
| `/interests` | Управление интересами |
| `/reminder` | Настройка напоминаний |
| `/config` | Настройки профиля |

## 🎮 Как это работает

### 1. Регистрация и выбор интересов
```
/start → Выбрать интересы (/interests) → Выбрать номера через запятую
Пример: 1,3,5
```

### 2. Ответить на дейлик
```
/daily → Ответить на вопрос → Система обновит стрик
```

### 3. Отслеживать прогресс
```
/streak → Посмотреть текущий и лучший стрик
/config → Посмотреть свой профиль и интересы
```

### 4. Настроить напоминания
```
/reminder 3 → Получать напоминания каждые 3 дня
```

### Модели БД

#### User (Пользователь)
- `telegram_id` - Уникальный ID в Telegram
- `username` - Username пользователя
- `first_name`, `last_name` - ФИ пользователя
- `is_active` - Активен ли пользователь

#### UserInterest (Интересы)
- `user_id` - Ссылка на пользователя
- `interest` - Название интереса

#### Daily (Дейлики)
- `question` - Текст вопроса
- `category` - Категория (связана с интересами)

#### UserDailyAnswer (Ответы на дейлики)
- `user_id` - Ссылка на пользователя
- `daily_id` - Ссылка на дейлик
- `answer` - Ответ пользователя
- `next_repeat_date` - Когда спросить снова
- `repeat_count` - Сколько раз уже спрашивали

#### UserStreak (День-стрик)
- `user_id` - Ссылка на пользователя
- `current_streak` - Текущий стрик (дней подряд)
- `longest_streak` - Лучший стрик
- `last_completed_date` - Когда последний раз выполнил дейлик
- `total_completed` - Всего выполнено дейликов

#### UserReminder (Напоминания)
- `user_id` - Ссылка на пользователя
- `reminder_interval_days` - Интервал напоминаний (1-7 дней)
- `next_reminder_date` - Когда придет следующее напоминание
- `is_enabled` - Включены ли напоминания

#### StudyProgress (История изучения)
- `user_id` - Ссылка на пользователя
- `topic` - Что изучил
- `study_time_minutes` - Время в минутах
- `date` - Дата изучения

## 🔒 Безопасность

- ✅ **Валидация входных данных** - Все входные данные проверяются
- ✅ **Обработка ошибок** - Graceful обработка всех исключений
- ✅ **Логирование** - Все ошибки логируются в файл
- ✅ **Лимиты сообщений** - Сообщения обрезаются до 4096 символов

## 📊 Система дня-стрика

Как работает стрик-система:

1. **Первый день** - Пользователь отвечает на дейлик → Стрик = 1
2. **Второй день подряд** - Ответ на дейлик → Стрик = 2
3. **Пропуск дня** - Стрик сбрасывается на 0
4. **Только одно попадание в день** - Можно ответить на разные дейлики, но стрик +1 только один раз в день

```
День 1: Ответ на дейлик → 🔥 Стрик: 1
День 2: Ответ на дейлик → 🔥 Стрик: 2
День 3: Без ответа     → 🔥 Стрик: 0 (сброс)
День 4: Ответ на дейлик → 🔥 Стрик: 1 (новый цикл)
```

## 🔧 Конфигурация

В файле `main.py` можно изменить константы:

```python
MIN_REMINDER_DAYS = 1       # Минимальный интервал напоминаний
MAX_REMINDER_DAYS = 7       # Максимальный интервал напоминаний
DAILY_REPEAT_INTERVAL = 3   # Интервал повторения дейликов (дней)
MAX_MESSAGE_LENGTH = 4096   # Максимальная длина сообщения
```
